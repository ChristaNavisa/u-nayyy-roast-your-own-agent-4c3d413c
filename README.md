## Entry

> I asked my agent for one line. It wrote a skill, a cron job, and a 400-line main.ts, then called the line a draft.

The roast names a real failing of the agent that built it: asked for one
line, it answers with a skill, a cron job and hundreds of lines of code —
and still calls the result a draft.

## How it runs

`main.ts` (Node 22) writes the line above to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(default `/output/entry.txt`), byte-identical on every run.
